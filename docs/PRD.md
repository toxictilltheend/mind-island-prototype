# 心屿｜情绪日记与自我关怀 · 简版 PRD

版本：0.6，2026-11-01。经用户授权，本文与交互原型一并公开在 GitHub 仓库。

当前版本采用自然手账风，支持天气、情绪词、文字、图片、语音及图形沙盘表达，首页优先呈现快速记录。第 9—10 节保留此前 ASCII 方向的设计历程；当前视觉与新增功能以第 11—12 节为准。

## 1. 产品定位与目标
面向 18—30 岁成年大学生和初入职场者的轻量自我关怀工具。以“记录当下 → 理解变化 → 选择小行动 → 回看感受”为核心流程，帮助用户表达情绪、发现记录中的共同情境、找到愿意尝试的自助方式。

首版验证低门槛记录和短练习是否有使用价值。产品不提供心理诊断、疾病预测或治疗，不替代专业支持。年龄和人群为设计假设，尚未完成用户研究。

## 2. 具体使用场景与痛点假设
以下基于题目背景推演，需访谈和可用性测试验证，不视为已证实的调研结论。

| 使用场景 | 用户想完成的事 | 痛点假设 | 产品响应 |
|---|---|---|---|
| 考试前、作业截止前 | 快速表达焦虑，重新开始一件事 | 长篇日记启动难，建议太多无法选择 | 两次点选完成基础记录；提供一个短练习 |
| 工作被否定、加班后 | 有一个不被评价的私人空间 | 社交平台存在暴露和评价压力 | 本地私人日记，文字可选，无公开动态 |
| 社交冲突后 | 分辨事件、感受和自己的需要 | 只记得“很难受”，难以描述 | 情绪选项、情境标签和可选一句话记录 |
| 睡前反复想白天的事 | 低负担收尾，选择放松方式 | 刷内容越看越晚，冥想课程太长 | 1 分钟呼吸、舒缓声景、轻活动步骤 |
| 周末回看近况 | 看见哪些情境反复出现 | 记了日记但难以复盘 | 最近 7/30 天趋势与情境出现次数 |
| 情绪尚可或开心时 | 记下让自己恢复力量的小事 | 情绪工具常只关注负面感受 | 正向情绪同样可记录，不追求“每天开心” |

## 3. 方案选择
推荐“轻量日记 + 规则推荐”：路径短、隐私成本低、能快速验证需求。纯内容库无法把建议与个人记录连接；开放式 AI 陪聊需要额外的安全与隐私治理，暂不进入首版。

## 4. 信息架构与核心流程
- 今日：情绪快速记录、最近趋势、推荐的小行动和最近日记。
- 日记：按时间查看、新增、编辑和删除。
- 洞察：选择 7/30 天窗口，查看趋势、常见情境及说明。
- 关怀：呼吸练习、舒缓声景、轻活动，支持结束和感受反馈。

主流程：选择当下感受 → 可选情境和文字 → 保存 → 出现相关关怀建议 → 自愿开始练习 → 可选反馈“有帮助 / 一般 / 不适合”。用户可以直接练习，不强制先写日记。

## 5. 首版功能规则与验收

| 功能 | 实现形式与规则 | 验收标准 |
|---|---|---|
| 情绪记录 P0 | 五档主观感受，必选；情境可选；文字最多 500 字；时间自动记录 | 未选择不可保存；成功后日记和趋势同步更新 |
| 日记回看 P0 | 时间倒序卡片；修改和删除需明确操作 | 编辑不增加记录数；删除后图表同步更新 |
| 情绪趋势 P0 | 每日均值折线，显示记录天数；缺失日期不补成零 | 空数据给出引导；仅一条显示点；仅比较所选窗口 |
| 情境观察 P0 | 统计用户主动选择标签的出现次数及同时记录的感受分布，一条可含多个标签 | 明确分母为记录数；显示每个情境中各类感受的记录条数；不把“同时出现”表述为原因 |
| 关怀推荐 P0 | 按最新感受和情境选择一个建议，用户可自由换方式 | 无数据使用通用建议，不伪装个性化结论 |
| 练习 P0 | 有引导的短呼吸、浏览器合成的舒缓声景、轻活动步骤 | 用户主动开始声音；随时可结束；结束声音停止 |
| 数据管理 P0 | 浏览器本地保存；个人数据 JSON 导出；清空需确认 | 刷新可恢复；导出不含示例；示例与个人数据分开 |
| 断网与异常 P0 | 无第三方资源依赖；存储失败提示并保留当次会话 | 不显示虚假的“已持久保存”提示；解析失败不崩溃 |

本次交付为交互原型：没有账号、跨设备同步、云端分析、后台通知、真人咨询、临床量表或 AI 服务。舒缓声景是本地合成声音，不是第三方音乐曲库。

## 6. 数据、隐私与表达
记录字段：ID、时间、感受档位、情境标签、文字；练习反馈单独保存。默认不采集姓名、定位、通讯录和健康设备数据；原型不接入统计 SDK。

网站及源代码公开，个人记录不会提交 GitHub。浏览器本地存储未加密，共用设备可能被他人查看，清除浏览器数据会丢失记录；首次使用和数据面板需说明。正式产品若增加云同步，应另外设计明确同意、访问控制、加密、删除与数据保留机制，完成适用地区的隐私合规评审。

不把情绪分为“好用户/坏用户”，不使用连续打卡惩罚；不暗示记录越多越健康。图表仅反映主动记录的片段，有自选偏差，不用于诊断和因果判断。困扰持续加重或影响日常生活时，提供寻求专业支持的入口；有即时危险时引导联系当地紧急服务或可信任的人，不承诺应用有人实时监测。

## 7. 后续版本
P1：更细的情绪词、用户自定义标签、按场景筛选内容、可控提醒、练习前后自评和周回顾。P2：在单独评审和同意机制下评估跨设备同步、经审校的内容库和可解释的 AI 摘要。暂不做公开情绪社区和诊断式评分。

## 8. 验证与上线门槛
先访谈 6—8 位目标用户，覆盖学生与职场新人，围绕最近一次情绪波动、现有应对方式、放弃记录原因和隐私顾虑提问。再用 5 位用户进行任务测试，观察能否独立记录、理解图表和结束练习。人数是建议计划，并非已完成的调研。

候选指标：首次记录完成率、首次记录耗时、7 日内自愿再次记录比例、练习开始/完成率、练习反馈、推荐不适合比例、删除/退出原因。试用前先定义分母和基线，首版原型不自动收集数据，也不以停留时长或连续打卡为健康收益指标。

上线检查：记录/编辑/删除/导出正确；示例隔离；无敏感数据和密钥；手机可用；键盘可操作；声音可停止；求助和数据说明可见；公开链接实际返回成功页面。

### 本次原型验证结果
已通过独立浏览器的桌面和 375px 手机布局检查，以及新增、编辑、删除/取消、刷新恢复、JSON 导出、示例隔离、7/30 日切换、文本安全显示、呼吸练习反馈、声音开启与停止、存储损坏和不可写场景测试。页面无运行错误，未请求外部字体、脚本、音频或统计服务。以上为功能检查，不等于用户需求或心理健康效果已经获得验证。

## 9. 历史设计：ASCII 交互升级

### 核心产品假设
有些用户在情绪波动时难以组织语言，也不愿填写一长串表单。天气隐喻、有限的引导问题和自由摆放，可以提供不同表达门槛。它们是否更容易使用、是否让人感到被理解，仍需目标用户试用验证；不能从视觉新颖直接推导心理健康收益。

### 三种方式，共享一份草稿
| 入口 | 交互方式 | 解决的表达障碍 | 保存结果 |
|---|---|---|---|
| 情绪小岛 | 主动选择小雨、多云、薄雾、微风、晴光，字符风景随选择改变；可选能量、需要和一句话 | 不知道怎么开头、没有力气打字 | 一条可无文字的天气记录 |
| 情绪终端 | 通过天气→需要→相关情境→可选一句话→确认，逐步表达；可以回到上一步 | 面对空白输入框不知所措 | 与其他入口相同结构的记录，保留对话式来源 |
| 情绪沙盘 | 点选树、山、灯塔、雨、桥、星、小屋、花、小船等字符物件，自由摆放、移动和撤销 | 感受复杂或不想直接描述事件 | 天气、可选说明和完整物件坐标快照 |

三个入口共享天气、能量、需要、标签、文字与布景，切换不会清空已选内容。界面变化服务于表达和回看，不设置情绪成绩、连续打卡或“低落让小岛枯萎”的惩罚。

### 天气标本与回看
每条记录可以打开对应的字符风景。用户可导出自己的单条风景为纯文本，也可以从历史风景开始新草稿；原记录保留。借用虚构示例时只借用布景，示例文字和情境留白，示例不能从私人导出入口导出。

### 实现与兼容规则
- 原有基础字段保持不变，新增可选 energy（0—100）、need、source（island/terminal/sandbox）、scene（版本与最多 12 个物件的类型及整数坐标）。旧日记不需要迁移才能读取。
- 编辑旧式日记保留扩展元数据；畸形可选字段单独清洗，不丢弃仍可读的基础记录。清空私人数据同时清空当前内存草稿和撤销历史。
- 保存后，重复点击未改变的同一草稿不会新增重复记录；修改草稿才可留下新的时刻。
- ASCII 动态可暂停，初始遵循设备“减少动态”偏好；字符画有文字说明，不逐帧播报给屏幕阅读器。沙盘拖放同时支持触屏指针、按钮添加、方向键移动、Delete 删除和撤销。
- 终端采用固定的本地引导，不对自由文字做 AI 推断；物件的个人意义由用户决定，不从“雨、山、桥”的摆放推断心理状态。
- 需要选项参与可解释的关怀推荐；不自动播放声音或联系他人。

### 下一步用户验证
比较“只选天气”“引导对话”“自由沙盘”的首次完成耗时、放弃点、模式切换和用户对记录意义的理解。重点观察：不写文字是否仍觉得表达充分、物件隐喻是否造成压力、回看风景是否比纯文字更容易想起当时情境。原型仍不自动采集埋点；试用应事先获得同意。

## 10. 历史设计：全站 ASCII 界面
根据用户反馈，本轮从局部字符插画升级为完整字符终端。取消固定侧栏和圆角卡片，使用顶部编号菜单、横向天气命令栏、全宽字符场景和打印日志式回看；字体、按钮、输入区域、比例条、洞察图表、关怀练习和弹窗采用统一的字符表达。

边框由真实 +、-、| 字符生成，随容器尺寸调整。能量条保留原生指针与键盘操作，视觉以字符条呈现；按钮保留语义和明确名称。减少动态设置继续生效。记录、沙盘快照、编辑、导出和浏览器存储兼容规则保持不变。

已通过全部四页在 1440、768、375 和 320px 下的布局检查，以及弹窗尺寸、字符图表、三种记录、键盘、撤销、旧数据、导出、声音停止和存储异常回归。样式统一不代表产品需求或健康效果已通过用户研究验证。

## 11. 当前视觉方向：自然手账风（取代 ASCII）
用户取消 ASCII 方向。本轮改为奶油纸色、森林绿与陶土色，配合舒展的衬线标题、插画场景、便笺和手账回看。保留顶部轻导航，避免恢复固定侧栏式后台布局。

小岛和沙盘使用可交互的 SVG 场景，物件采用图形化树、灯塔、小屋和星等；“情绪终端”改为“聊聊此刻”，以写给自己的信逐步表达。图表、图标、弹窗和关怀练习均恢复直观图形表达。风景导出改为 SVG 插画，正文按文本转义，不执行输入内容。

已有记录的物件类型和逻辑坐标保持不变，旧风景可以直接以新插画打开。手机增加快捷天气选择；旧数据、保存、编辑、导出、引导流程和图形拖动/键盘操作均通过回归，四页在 1440/768/375/320px 下通过布局检查。此前 ASCII 章节仅记录设计迭代，不代表当前风格。

## 12. 多方式表达与页面主次
首页以“快速记录此刻”为主任务：选一种天气即可保存；情绪词、文字、照片、语音、能量与需要均可选。桌面以明确的主记录面板和深绿保存按钮引导，手机先呈现记录表单，再呈现小岛反馈。图片/语音和能量/需要分别按需展开，引导对话、自由沙盘及历史回看保留为次级入口。

情绪词从 12 个常用词中选择，最多 3 个，帮助用户不写长文也能表达。照片最多 3 张，支持 JPG/PNG/WebP，原图每张不超过 8MB；在本地处理为最长边 1280px 的 JPEG 后存储，可预览、移除和放大回看。语音每条一段，点击并授权后才开启麦克风，最多 60 秒，可停止、取消和回听；不支持录音时可导入不超过 5MB 的音频文件。不做自动转写或内容分析。

附件保存在当前浏览器的 IndexedDB，日记只存引用；既有记录可继续读取和编辑。录音离开页面、取消或切到后台会结束并释放麦克风。JSON 完整备份包含附件数据及缺失附件列表；删除或清空同步处理本地附件。原型当前提供导出，不提供备份导入或跨设备同步。网站代码公开，私人记录和附件不上传 GitHub；清理浏览器数据会丢失本地内容。

已验证情绪词数量限制、照片格式与体积限制、本地缩放、录音授权拒绝、导入替代路径、60 秒自动停止、离开取消、保存/刷新/编辑/回看/备份/清空，以及桌面和 768/375/320px 布局。录音自动化使用虚拟音源，真实设备的权限提示及浏览器差异仍取决于运行环境。全部为功能测试，不代表心理健康效果得到验证。
